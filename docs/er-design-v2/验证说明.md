## 用户环境验收
在临时数据库中运行：
```bash
psql -v ON_ERROR_STOP=1 -d your_test_database -f docs/er-design-v2/schema.sql
psql -v ON_ERROR_STOP=1 -d your_test_database -f docs/er-design-v2/acceptance.sql
```
需PostgreSQL 15+。验收预期输出All synthetic acceptance checks passed并最终ROLLBACK。
schema.sql仅首次运行；重复运行会因schema已存在报错，不自动删除旧库。
acceptance.sql会回滚数据，但序列仍可能消耗ID，这是PostgreSQL正常行为。

在GitHub查看主文档和完整ER图.md的Mermaid块是否正确呈现；
若使用旧渲染器不支持实体中文别名，更新渲染器或移除方括号别名。
完整图较大，汇报优先展示主文档的功能主线图。

## 尚需科研质控
- 一项转化的底物/产物与来源是否由原文证明；化学式及电荷是否平衡。
- 功能注释是否只是计算预测；experimental是否对应具体底物催化实验。
- 菌株/蛋白身份一致性，宿主靶点与实验宿主物种一致性。
- 原文测量方向与endpoint相符；相对丰度不当作直接促生长。
- 单跳证据不能自动变成整条因果链；阴性和矛盾证据不删除。
